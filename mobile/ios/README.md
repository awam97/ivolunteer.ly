# iOS Shell

This folder is a hand-written Flutter iOS shell scaffold for the I Volunteer mobile app.

The full Xcode project file and generated Flutter build settings are normally created by `flutter create .`.

Key files you would normally expect in a generated Flutter iOS project:

- `ios/Runner/AppDelegate.swift`
- `ios/Runner/Info.plist`
- `ios/Runner/Assets.xcassets/`
- `ios/Runner.xcodeproj/project.pbxproj`
- `ios/Flutter/Debug.xcconfig`
- `ios/Flutter/Release.xcconfig`

When you run Flutter on a Mac with Xcode, it will generate the remaining project metadata.
