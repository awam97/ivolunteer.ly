# Android Shell

This folder is a hand-written Flutter Android shell scaffold for the I Volunteer mobile app.

It is intentionally minimal here because the full Gradle wrapper and generated project metadata are normally created by `flutter create .`.

Key files you would normally expect in a generated Flutter Android project:

- `android/app/src/main/AndroidManifest.xml`
- `android/app/src/main/kotlin/com/ivolunteer/i_volunteer_mobile/MainActivity.kt`
- `android/app/src/debug/AndroidManifest.xml`
- `android/app/src/profile/AndroidManifest.xml`
- `android/app/build.gradle`
- `android/build.gradle`
- `android/settings.gradle`

When you run Flutter on a full local SDK, it will generate the remaining build files for you.
